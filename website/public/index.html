The pitch

Home control that travels with you.

Most smart-home stacks assume one forever house, one cloud login, and a weekend of YAML. Overlink assumes you plug a Core into a new LAN, join Wi‑Fi from your phone, discover what’s already there, and start conducting the room.

Phone UI by default. WallDeck when you want a panel on the wall. CyberDeck when the room needs IR/RF muscle. SoftAP → Arrival → CTRL. Optional cloud bridges and an Overlink-owned relay when you leave the building.

If the first hour needs a laptop, we failed.

Hardware family

Core required. Peers optional.

Ship what the house needs. Absent peers degrade gracefully — Core + phone stays useful.

Required

Overlink Core

ESP32-S3 brain with TF storage, SoftAP onboarding, portable discovery, connectors vault, Party Tricks, and relay dial-out. Serves the CTRL phone UI at overlink.local.

Panel

WallDeck

CYD thin client for the wall. Scenes, zones, AV now-panel, Grace Party second screen, and Party Tricks chips that call Core — no house secrets burned into the glass.

Room peer

CyberDeck

IR + RF peer for TVs and the weird physical layer. If it’s offline, Overlink hides deck affordances instead of pretending the house is broken.

Capability map

Everything you actually use — and a few things that make people grin.

Arrival

SoftAP → blank grid

Join house Wi‑Fi from the phone. Core creates a blank per-SSID grid on the TF card — empty rooms/devices, ready for discovery. No reflash. No av_secrets.h edits on site.

Discovery

Portable LAN sweep

Subnet fingerprints for WLED, Hue, Cast, CyberDeck, Fire/Vizio/PS5 ports, RTSP cameras, plus WiZ broadcast MAC map. Catalog ranks lights → AV → cameras.

CTRL

Phone + WallDeck IA

Home · Zones · Scenes · Ops. Basement CTRL scene grid, Fire apps, volume, WLED, Hue rooms. WallDeck resumes last tab from NVS.

Hue

Link without compile secrets

Press the bridge button, tap Link Hue. Username lands in the per-grid SD vault. Sync rooms into zones.

Connectors

Bridge + cloud vault

Home Assistant import/control. Nest/Ring token vault stubs. Secrets stay on the grid’s SD path — not in firmware.

Relay

Expose without inbound ports

Core dials out to your Overlink relay. Phone attaches over WSS with a short-lived session. Toggle expose off — remote path dies.

Cameras

Snapshot tiles

RTSP :554 discovery + HTTP JPEG proxy paths (D‑Link-class stills). Bandwidth-honest on ESP — tiles, not an NVR.

Party

Showy on purpose

mDNS+BLE sweep, BLE name billboard / cycle, light stampede, Chromecast stinger, open-printer text blast — family fun with a LAN awareness lesson.

Games

Grace Party Pack

Phone as controller, WallDeck/TV as the room view. Party mode that doesn’t need another SaaS account.

Setup

From box to CTRL without a ritual.

Flash Core

Use Flash from browser (Chrome/Edge + USB) or PlatformIO USB once. Insert a TF card.

Join SoftAP

Phone joins open Wi‑Fi Overlink-Setup. Portal at http://192.168.44.1.

Pick house Wi‑Fi

Save SSID + passphrase. Core creates/activates a blank grid for that network and reboots into STA.

Arrival Wizard

On http://overlink.local — scan, add known devices, optional rooms, Link Hue if present.

Optional peers

Flash WallDeck / CyberDeck when you want panels or IR. They find Core via mDNS.

Developer path

Clone & build

Monorepo under firmware/overlink-core, walldeck, cyberdeck. Copy av_secrets.example.h only if you want local overrides — Arrival + SD vault are the product path.

cd firmware/overlink-core && pio run -t upload
OTA later: pio run -e overlink-core_ota -t upload

Relay

Off-site optional

Run services/overlink-relay on a host you control. Ops → Expose → enroll code. No router port forwards at the house.

Web flash

Connect the board. Flash from the browser.

Chrome or Edge on desktop. USB cable. ESP Web Tools talks Web Serial — no PlatformIO required for a first Core or WallDeck bring-up.

Overlink Core · ESP32-S3

Waveshare ESP32-S3-LCD-1.47 (and compatible S3 boards). Erases and installs bootloader + partitions + firmware.

If the button is disabled, your browser lacks Web Serial — use Chrome/Edge, or flash via USB with PlatformIO.

WallDeck · ESP32 (CYD)

ESP32-2432S028 class panels. Thin client — points at Core over the LAN.

Hold BOOT if the serial port won’t appear. After flash, both decks currently announce as walldeck — distinct hostnames are on the roadmap.

Roadmap

Where this goes if we refuse to be boring.

The coolest honest future — still self-reliant, still portable, still allergic to “buy another hub.”

Now

Self-reliant arrival + Party Tricks

SoftAP grids, portable discovery, CTRL, Hue link, HA bridge, relay skeleton, cameras tiles, WallDeck party chips, web flash.

Next

Real cloud sign-in that toggles one device

Finish Nest or Ring end-to-end OAuth from the phone Connectors panel. Tokens encrypted-at-rest on SD. Prove “new house, one login, one win.”

Next

Remote phone app path

Feature-detect overlink.local, fall back to relay URL, same CTRL chrome off-LAN. Cellular stampede optional. Expose toggle remains the kill switch.

Soon

Fleet identity for WallDecks

walldeck-a / walldeck-b, room binding, presence LED sync, shared Grace scoreboard across panels.

Soon

Camera honesty upgrade

ONVIF GetSnapshotUri, basic auth, bandwidth caps, and relay snapshot ferry for off-site tiles — still not an NVR.

Horizon

Matter only via bridges we don’t own

Never pretend the ESP is a Thread border router. Import Matter entities through HA/local hubs the house already paid for.

Horizon

Overlink App Store (local)

SD-loaded “tricks packs” and scene packs you can air-drop between grids — Party Tricks, Grace packs, AV profiles — without a cloud SKU.

Dream

Arrival that feels like a film cold open

Plug in → SoftAP → join → lights identify in a wave → Cast stinger on the nearest TV → WallDeck wakes on the last scene. Guests think you live here.

Principles

Keep the stick honest

No on-site IDE as a setup step. No baking house IPs into firmware. ESP is not a full Matter controller or NVR. Local first; cloud is a connector, not the landlord.
