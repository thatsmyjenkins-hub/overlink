Installer

Flash from the browser

Plug the board in over USB. Use Chrome or Edge on a computer. Pick the serial port when prompted. First install erases the flash.

1 · Overlink Core

Chip family: ESP32-S3

After flash: join SoftAP Overlink-Setup, pick house Wi‑Fi, open overlink.local.

2 · WallDeck

Chip family: ESP32 (CYD 2.8")

Needs Core already on the same LAN. WallDeck resolves overlink.local.

Troubleshooting

Port missing / failed

Hold BOOT while plugging in. Close serial monitors. On macOS, grant Chrome serial permission. Drivers: CP210x / CH340 depending on the board. Still stuck? pio run -t upload from the monorepo USB once, then use OTA forever after.
